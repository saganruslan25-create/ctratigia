Province Map Editor

Малюєте кордони → заливаєте область → їй автоматично присвоюється унікальний ID-колір і власник. Експорт: PNG-маска + JSON з даними.

Полотно

Введіть будь-який кастомний розмір (напр. 5120). Стандарт для великої карти — 4096.

Підкладка (референс-карта)

Завантажте скріншот реальної карти — малюйте кордони поверх неї. У фінальний PNG підкладка не потрапляє.

Інструмент

Малюйте чорні лінії, щоб розділити карту на замкнені області. Незамкнена лінія = провінції зіллються.

Авто-розбиття на провінції

Спочатку обведіть контур області інструментом «Кордон» (замкнена лінія навколо країни/регіону з фото), потім оберіть «Розбити на провінції» і клікніть всередині контуру. Менший розмір / вища хаотичність = більше дрібних нерівних провінцій, як у HOI4. Владелець і назва-префікс беруться з полів нижче.

Відображення

ID-кольори на початку (1,0,0 / 2,0,0 …) майже чорні й непомітні на екрані. Ця опція лише підсилює яскравість картинки, що ви бачите — на збережений PNG і на дані провінцій вона не впливає.

Нумерація та власник

Клік інструментом «Заливка» всередині замкненої області створить нову провінцію з ID 1, кольором (1,0,0), власником і типом, обраними вище. Ці параметри також застосовуються до імпорту GeoJSON та авто-розбиття.

Провінції (0)

Імпорт GeoJSON (кордони → провінції)

Якщо увімкнено «Розбити...», кожен Polygon/MultiPolygon буде автоматично розбитий на дрібні провінції (згідно з повзунками «Розміру» та «Хаотичності»). Якщо вимкнено — кожна область стане однією великою провінцією. Після імпорту одразу можна натиснути «Завантажити province_map.png».

Імпорт міст/сіл (точки → провінції)

За замовчуванням тут вже стоять межі карти України (той самий bounding box, що й у вашому вихідному GeoJSON областей). Змінюйте тільки якщо імпортували інший контур.
Кожна точка стане окремою провінцією з відповідним типом (metropolis/city/town/village) і назвою, або перейменує provincію під собою, якщо увімкнено опцію вище. Власник береться з поля «Власник» вище.

Продовжити попередню роботу

Імпорт підхопить усі існуючі провінції та автоматично виставить «Наступний ID» на перший вільний номер.

Експорт

Вкажіть потрібний розмір файлу. Система автоматично стисне або розтягне карту без втрати кольорових ID (найближчий сусід).
